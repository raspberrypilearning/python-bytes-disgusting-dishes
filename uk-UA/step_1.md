<h2 class="c-project-heading--task">Надрукуй огидне привітання</h2>

\--- task ---

Скористайся <code>print()</code>, щоб вивести привітальне повідомлення для своєї картки з огидним рецептом.

\--- /task ---

<h2 class="c-project-heading--explainer">Підготуйся</h2>

Тебе щойно взяли на роботу друкарем у дуже дивний ресторан.  
Твоє завдання? Друкувати картки з огидними рецептами для нового меню ресторану!

У Python текст називається <strong>рядком</strong>. Щоб Python показав рядок на екрані, можна скористатися функцією <code>print()</code>.  
Щоразу, коли ти використовуєш <code>print()</code>, Python починає виведення з нового рядка.

Розпочни з друку привітального повідомлення для своєї огидної страви.

print()
